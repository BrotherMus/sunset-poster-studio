Sunset Poster Studio turns your own photos and a caption into multi-panel crime-epic poster art: tilted tiles with thick borders, sunset and neon colour grades, film grain and glow, and big bold lettering, in an original design of its own. It runs offline in the browser from static files, keeps your photos on your machine, and exports a PNG at 1920 x 1080, 1080 x 1350 or 1080 x 1080.

## Run it

```sh
node serve.ts
```
