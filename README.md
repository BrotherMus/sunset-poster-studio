Sunset Poster Studio turns your own photos and a caption into multi-panel crime-epic poster art: skewed panel layouts with thick borders, sunset and neon gradient-map grades, film grain, glow and big outlined lettering on a coloured slab. It runs offline in the browser from static files (your photos never leave your machine) and exports a PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080.

## Run it

```sh
node serve.ts
```
