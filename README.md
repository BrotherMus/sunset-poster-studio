Sunset Poster Studio turns your own photos and a caption into multi-panel crime-epic poster art: tilted panel grids with thick borders, Vice City-style sunset and neon colour grades, film grain, glow and bold slab lettering. Crop each panel, hit "Surprise me" for a new look, and export a PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080, all offline in the browser.

## Run it

```sh
node serve.ts
```
